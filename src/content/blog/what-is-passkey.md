「大文字・小文字・数字・記号を混ぜて12桁以上」「過去に使ったパスワードは不可」「定期的な変更を推奨」……。

Webサービスを利用するたびに求められるパスワードの管理に、うんざりした経験はありませんか？
複雑なパスワードを覚えるのは人間の脳には限界があり、かといって使い回せば一度の漏洩で芋づる式にアカウントが乗っ取られるリスクがあります。

そんな**「パスワードという仕組み自体の限界」を根本から解決する決定打**として、Google、Apple、Microsoftなどが一斉に導入を進めているのが **「パスキー（Passkey）」** です。

今回は、最近耳にする機会が増えたパスキーについて、難しい専門用語をできるだけ噛み砕きながら、仕組み・メリット・注意点まで分かりやすく解説します。

## 1. パスキーとは？ 一言でいうと

パスキーとは、**「英数字のパスワードを入力する代わりに、スマホやPCの指紋・顔認証（生体認証）で安全にログインする技術」**です。

```text
【従来のログイン】
IDを入力 ➔ 覚えたパスワードを入力 ➔ （二段階認証コードを入力） ➔ ログイン完了

【パスキーのログイン】
IDを入力 ➔ スマホの指紋/Face IDをピッ ➔ 瞬時にログイン完了！
```

パスワードを「自動入力」しているわけではありません。
そもそも**パスワードそのものを一切使わない（パスワードレス）**仕組みになっています。

## 2. なぜ安全？ パスキーの仕組み（公開鍵暗号）

パスキーが従来のパスワードと決定的に違うのは、国際標準規格「FIDO2（ファイド・ツー）」に基づく**「公開鍵暗号方式」**を採用している点です。

パスキーを設定すると、ペアとなる2つの「鍵」が作られます。

```text
ユーザーの端末（スマホ・PC）                Webサービスのサーバー
┌───────────────────────┐                  ┌──────────────────────┐
│  【秘密鍵】           │                  │  【公開鍵】          │
│  端末の安全な領域に   │                  │  サーバーに保存      │
│  厳重保管（外に出ない）│                  │  （盗まれても無害）  │
└───────────────────────┘                  └──────────────────────┘
```

1. **秘密鍵（プライベートキー）**
   - あなたのスマートフォンやパソコン内の「セキュア領域（絶対に外部からアクセスできない金庫のようなチップ）」に保存されます。
   - インターネット経由で外部に送信されることは絶対にありません。
2. **公開鍵（パブリックキー）**
   - ログイン先のWebサービス（GoogleやAmazonなど）のサーバーに登録されます。
   - 一般に公開されても悪用できない仕組みの鍵です。

### ログイン時の流れ
ログインする際、サーバーから「この計算問題を解いて署名して送って」という課題（チャレンジ）が届きます。
あなたがスマホで指紋や顔認証を通すと、スマホ内の**秘密鍵が電子署名を行ってサーバーに送り返し、公開鍵で照合されてログインが許可**されます。

「合言葉（パスワード）」をインターネット上でやり取りしないため、途中で盗み見られる心配が原理的に存在しません。

## 3. パスキーの4大メリット

### ① フィッシング詐欺に100%引っかからない（最強のメリット）
偽の銀行やショッピングサイトに誘導してパスワードを入力させる「フィッシング詐欺」。
パスキーを使っている場合、**偽サイトに秘密鍵を渡すことは物理的に不可能**です。

ブラウザとOSが「現在開いているURL」を厳格にチェックするため、本物のサイト（例: `amazon.co.jp`）以外ではパスキーが反応しません。見た目が本物そっくりの偽サイトであっても、秘密鍵が署名を拒否するため、詐欺に遭うリスクを完全にシャットアウトできます。

### ② サーバーから情報が漏洩しない
従来のパスワード認証では、Webサービスの運営企業がハッキングされると、ユーザーのパスワードが流出する恐れがありました。
しかし、パスキーでサーバーに預けているのは「公開鍵」だけです。万が一サーバーのデータベースが丸ごとハッカーに盗まれても、公開鍵からは秘密鍵を復元できないため、アカウントが乗っ取られることはありません。

### ③ 面倒なパスワードの作成・記憶・管理がゼロになる
「記号を1文字以上入れてください」「前回のパスワードと同じものは使えません」といったストレスから完全に解放されます。パスワード管理アプリに課金したり、手帳にメモしたりする必要もありません。

### ④ ログインが圧倒的に速い（UXの劇的な向上）
指紋を当てる、あるいは画面をチラッと見るだけで1秒未満でログインが完了します。
外出先で慌ててログインするときや、クレジットカード情報の入力を求められたときでも、快適そのものです。

## 4. パスキーと従来のパスワードの比較

| 項目 | 従来のパスワード | パスキー（Passkey） |
| :--- | :--- | :--- |
| **ログイン方法** | 文字列の手入力 | **指紋・顔認証（またはPIN）** |
| **フィッシング耐性** | 偽サイトに入力すると盗まれる | **原理的に盗まれない（完全耐性）** |
| **サーバー流出リスク** | サーバー攻撃で流出の危険あり | **公開鍵のみのため流出しても安全** |
| **パスワードの使い回し** | 危険だが多くの人がやってしまう | **そもそもパスワードが存在しない** |
| **二要素認証の手間** | SMSやアプリでコード確認が必要 | **生体認証そのものが二要素認証を兼ねる** |

## 5. デバイスの壁を破る！パスキー管理に「Bitwarden」を特におすすめする理由

パスキーを使い始めると、多くの人が**「OSやブラウザの壁（エコシステムの分断）」**という壁にぶつかります。

- **Apple（iCloudキーチェーン）**: iPhoneやMac同士では便利だが、**Windows PCやAndroidスマホでは使えない**
- **Google（Googleパスワードマネージャー）**: AndroidやChromeでは快適だが、**iOSやSafariとの相性に制限がある**

「普段はiPhoneを使っているけれど、自宅や職場のPCはWindows」という方は日本に無数にいます。この場合、標準機能だけでは**「スマホで作ったパスキーでWindowsのブラウザにログインできない」**という大きな不便が生じてしまいます。

この問題を一発で解決し、パスキーを真に快適にしてくれるのが、オープンソースのパスワードマネージャー**「Bitwarden（ビットワーデン）」**です。

### なぜパスキー管理に Bitwarden が最強なのか？

#### ① 完全なマルチプラットフォーム＆マルチブラウザ対応
Bitwarden最大の強みは、**プラットフォームの壁が一切存在しないこと**です。
- **対応OS**: Windows, macOS, Linux, iOS, Android
- **対応ブラウザ**: Chrome, Firefox, Edge, Safari, Brave, Opera, Vivaldi

iPhoneで登録したパスキーを使って、職場のWindows PC（Chrome）で即座にログインする――といった連携がシームレスに行えます。スマホをかざしてQRコードを読み取るような二度手間も必要ありません。

#### ② オープンソースと「ゼロ知識暗号化」による鉄壁の安全性
Bitwardenはソースコードが全世界に公開されており、第三者セキュリティ機関による監査を定期的に受けています。  
データは端末側でエンドツーエンド暗号化（AES-CBC-256）された状態で同期されるため、**Bitwardenの運営元であってもあなたの秘密鍵を復号して見ることは原理的に不可能（ゼロ知識暗号化）**です。

#### ③ 無料プランでも端末無制限でパスキー同期が使える
多くのサードパーティ製マネージャーが有料サブスクリプションを必須とする中、Bitwardenは**無料プラン（Free）のままでデバイス台数無制限のパスキー同期と自動入力**に対応しています。個人で利用する分には、無料のまま不自由なく使い続けられます。

#### ④ 将来の機種変更や「脱エコシステム」でも安心
特定のOS（AppleやGoogle）のキーチェーンに依存してしまうと、将来「iPhoneからAndroidに乗り換えたい」「WindowsからMacに変えたい」と思ったときに、全サービスのパスキーを再登録しなければならず大変な労力がかかります。  
Bitwardenにパスキーを集約しておけば、どんな端末に買い替えてもアプリをインストールしてログインするだけで、すべてのパスキーが即座に引き継がれます。

#### ⑤ 従来のパスワードとパスキーを一元管理できる
Webの世界が100%パスキーに移行するにはまだ数年かかります。Bitwardenなら、未対応サイトの「複雑なパスワード生成・保存」と、対応サイトの「パスキー」を同じ画面で一元管理できるため、移行期のツールとしてこれ以上ない選択肢です。

## 6. デメリットや気になる疑問・注意点

非常に優れたパスキーですが、移行期ならではの注意点も存在します。

### Q1. スマホを紛失・機種変更したらログインできなくなる？
**A: クラウド同期（BitwardenやiCloud等）を利用していれば安心です。**  
BitwardenやApple/Googleのアカウント同期を利用していれば、パスキーは暗号化されて安全に同期されます。万が一スマホを水没させたり紛失したりしても、新しい端末でサインインすればログイン権限を失うことはありません。

### Q2. すべてのサイトで使えるの？
**A: まだ対応していないWebサイトも多いです。**  
Google、Amazon、Apple、Microsoft、メルカリ、任天堂、X、Yahoo! JAPAN、GitHubなど主要サービスでは対応が完了していますが、中小規模のWebサイトでは従来のID・パスワードが必要です。Bitwardenなどを併用して徐々に移行するのがおすすめです。

### Q3. 家族や同僚とPCを共有している場合は？
**A: 共有PCでの利用には注意が必要です。**  
PCにパスキーを保存する場合、そのPCを使える人がWebサービスにもアクセスできてしまうリスクがあります。Bitwardenのブラウザ拡張機能では「一定時間操作がないと自動でボールト（金庫）をロックする」設定が可能なため、共有環境では自動ロック機能を必ず有効にしておきましょう。
